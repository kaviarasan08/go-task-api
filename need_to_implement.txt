Phase 3 — Database and testing
	1. Add a proper database migration tool.
	2. Configure PostgreSQL connection pooling.
	3. Learn unit testing in Go.
	4. Test service and repository logic.
	5. Write HTTP handler tests using httptest.
	6. Test error cases, not just successful requests.
	7. Learn when database transactions are necessary.

Phase 4 — Docker
	1. Learn Docker fundamentals.
	2. Write a Dockerfile for your Go API.
	3. Create a docker-compose.yml for Go and PostgreSQL.
	4. Configure environment variables.
	5. Run the entire application using Docker.
	6. Learn Docker volumes, networking, and persistent database storage.
